# Krey-ITSec C4-BotnetOS 
![1000023528](https://github.com/user-attachments/assets/ab0b0680-59f2-438d-bcf2-1fe04efe6b2f)

C4 BotnetzOS von Krey-ITSec ist für verschiedene Betriebssysteme gedacht. Laut derzeitiger Planung, ist die C4-Anwendungsumgebung für den Raspberry PI, Docker/LXD Container, OVA VirtualBox Virtuelle Maschine und ein ISO Abbild gedacht. 
Es ist ein von mir erfundener Ransomware Zweig, der ein neues Krey-ITSec C4-BotnetOS Betriebssystem nach exfiltration der Dateien installiert. Nach eingabe des richtigen Cryptografischen Schlüssels, wird das Ausgangssystem wieder installiert und gebootet.
